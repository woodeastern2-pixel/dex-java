# SignPDF v1.9.0 출시 체크리스트

## 앱 기준
- 패키지: `com.easternwood.signpdf`
- versionCode: `24`
- versionName: `1.9.0`
- 기본 언어: 한국어
- 지원 언어: 한국어, English
- 가격: 무료
- 광고: 배너 + 보상형 전면광고
- 인앱 결제/구독: 없음

## 핵심 기능
- PDF 열기, 암호 PDF 열기, 서명·필기, 저장·공유
- 이미지 PDF 변환
- PDF 병합, 페이지 관리·추출·분할
- 저장 위치와 최근 문서
- 한국어/영어 전환

## 무료 제한 및 60분 보상
- 결과물 생성·저장 성공 시에만 월간 무료 10회에서 1회 차감
- 단순 열기와 실패 작업은 차감하지 않음
- 한도 도달 시 보상형 전면광고 안내 표시
- 광고 시청 전 보상과 60분 지속시간을 명확히 고지하고 취소 선택 제공
- 광고를 끝까지 시청한 경우에만 60분 전체 기능 부여
- 광고 중단·닫기·표시 실패 시 보상 미부여
- 보상 중 작업 횟수 무제한, 서명 저장, 병합, 페이지 관리, 고급 이미지 PDF 사용 가능
- 보상 중 홈 배너 숨김
- 앱 재실행 후 남은 보상시간 유지
- 60분 만료 후 제한과 배너 정상 복귀
- 기기 시각을 보상 시작 전으로 되돌리면 보상 무효 처리
