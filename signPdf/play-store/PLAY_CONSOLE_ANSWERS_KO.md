# SignPDF Play Console 제출 답안 초안

최종 점검일: 2026-09-03

현재 SignPDF 코드(`com.easternwood.signpdf`, v1.9.0)를 기준으로 작성했습니다. Play Console의 실제 최신 질문을 우선합니다.

## 1. 기본 설정
- 앱 이름: `SignPDF - PDF 서명·필기`
- 기본 언어: 한국어
- 앱 또는 게임: 앱
- 무료/유료: 무료
- 카테고리: 도구
- 광고 포함 여부: 예
- 인앱 상품 또는 구독: 아니요

## 2. 앱 액세스
- 로그인, 회원가입, 별도 계정: 필요 없음
- 특정 기능을 위한 외부 자격 증명: 필요 없음
- 고급 기능은 사용자가 보상형 전면광고 시청을 선택하면 60분 동안 열림
- PDF 비밀번호는 사용자가 소유한 암호 PDF를 기기에서 열 때만 사용

따라서 앱 검토를 위한 별도 로그인 정보는 필요하지 않습니다.

## 3. 광고
- AdMob 배너 광고: 예
- AdMob 보상형 전면광고: 예
- 보상: 광고를 끝까지 시청하면 60분 동안 작업 제한과 고급 도구 제한 해제, 배너 숨김
- 광고 시청은 선택 사항이며 기본 무료 기능은 계속 사용 가능
- 필요한 지역에서 Google UMP 동의 및 광고 개인정보 설정 제공

## 4. 데이터 보안 — 앱 자체 처리
- PDF와 이미지 내용 및 PDF 비밀번호를 개발자 서버로 전송하지 않음
- 편집, 변환, 병합, 서명 및 저장은 기기에서 처리
- 원본 문서를 덮어쓰지 않고 새 PDF로 저장
- 최근 파일 정보, 무료 사용 횟수, 보상 시작·종료 시각 및 저장 서명은 기기에 로컬로 저장될 수 있음

## 5. 데이터 보안 — Google Mobile Ads SDK
현재 Google Mobile Ads SDK 25.4.0을 사용합니다. 광고 제공, 분석 및 부정행위 방지 목적으로 다음 정보가 Google에 의해 처리될 수 있으므로 최신 SDK 공개 자료와 대조하여 Data Safety에 반영합니다.

- IP 주소를 통해 추정될 수 있는 대략적인 위치
- 앱 실행, 광고 시청과 같은 앱 활동
- 진단 및 성능 정보
- Android 광고 ID, App Set ID 등 기기 또는 기타 ID

## 6. 계정 삭제
SignPDF 자체 사용자 계정이 없으므로 앱 계정 삭제 기능 대상이 아닙니다. 로컬 데이터는 앱 내 항목 삭제 또는 Android 앱 데이터 삭제로 제거할 수 있습니다.

## 7. 타깃층 및 콘텐츠
- 특별히 어린이를 대상으로 제작하지 않음
- PDF 문서 유틸리티/생산성 도구
- 폭력, 성적 콘텐츠, 도박 등 자체 콘텐츠를 제공하지 않음

## 8. 권한 및 파일 접근
매니페스트 직접 권한:
- `INTERNET`
- `ACCESS_NETWORK_STATE`

PDF/이미지 선택은 Android Storage Access Framework를 사용하므로 광범위한 저장소 권한을 직접 요청하지 않습니다.

## 9. 제출 직전 확인
- 실제 AdMob 앱 ID, 배너 ID, 보상형 전면광고 ID 적용
- 공개 HTTPS 개인정보처리방침 URL 입력
- Data Safety와 실제 SDK 동작 일치 확인
- 광고, 콘텐츠 등급, 타깃층 설문 완료
- 서명된 Play AAB 사용
- Galaxy S26 Ultra 기준 기본/보상/만료 흐름 확인
