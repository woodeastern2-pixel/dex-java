# SignPDF Play Console 제출 답안 초안

최종 점검일: 2026-08-19

이 문서는 현재 SignPDF 코드(`com.easternwood.signpdf`, v1.5.3)를 기준으로 Play Console 입력 시 참고하기 위한 초안입니다. Google Play Console의 실제 질문 문구가 변경되면 화면에 표시되는 최신 질문을 우선합니다.

## 1. 기본 설정
- 앱 이름: `SignPDF - PDF 서명·필기`
- 기본 언어: 한국어
- 앱 또는 게임: 앱
- 무료/유료: 무료
- 카테고리: 도구
- 광고 포함 여부: 예
- 인앱 상품: 예 (`signpdf_pro`, 1회성 구매)

## 2. 앱 액세스
- 로그인 필요: 아니요
- 회원가입 필요: 아니요
- 별도 계정 필요: 아니요
- 특정 기능을 사용하기 위한 외부 자격 증명: 아니요
- PDF 비밀번호는 사용자가 자신의 암호화된 PDF를 열 때만 입력하며 앱 계정 비밀번호가 아닙니다.

따라서 일반적으로 "모든 기능을 제한 없이 액세스할 수 있음"에 해당합니다.

## 3. 광고
- 앱에 광고가 포함되어 있습니까?: 예
- 무료 사용자는 Google Mobile Ads SDK(AdMob) 배너 광고가 표시될 수 있습니다.
- SignPDF Pro 구매 사용자는 앱 내 배너 광고가 제거됩니다.
- 광고 동의가 필요한 지역에서는 Google UMP를 사용합니다.

## 4. 데이터 보안 — 앱 자체 처리
### 문서 및 이미지
- 사용자가 여는 PDF/이미지 내용은 SignPDF 개발자 서버로 전송하지 않습니다.
- PDF/이미지 편집과 이미지→PDF 변환은 기기에서 처리합니다.
- 원본 문서는 덮어쓰지 않고 새 PDF로 저장합니다.

### PDF 비밀번호
- 암호 PDF를 여는 데 사용합니다.
- 앱의 영구 저장소에 저장하지 않습니다.
- 개발자 서버로 전송하지 않습니다.

### 최근 파일 정보
- 파일 이름, 파일 형식, Android가 제공한 URI가 기기 로컬 저장소에 기록될 수 있습니다.
- 개발자 서버로 전송하지 않습니다.
- 최근 파일 목록 또는 앱 데이터 삭제로 제거할 수 있습니다.

## 5. 데이터 보안 — Google Mobile Ads SDK
현재 앱은 Google Mobile Ads SDK 25.4.0을 사용합니다.

Google의 현재 SDK 공개 자료를 기준으로 다음 데이터가 광고, 분석 및 부정행위 방지 등을 위해 자동으로 수집/공유될 수 있으므로 Play Console Data Safety에서 반드시 반영합니다.

- 대략적인 위치: IP 주소를 통해 추정될 수 있음
- 앱 활동: 앱 실행, 탭 등 사용자 제품 상호작용
- 앱 정보 및 성능: 진단/성능 정보
- 기기 또는 기타 ID: Android 광고 ID, App Set ID 등

Google은 Mobile Ads SDK가 수집하는 데이터가 전송 중 TLS로 암호화된다고 안내합니다.

주의: 실제 Data Safety 답변은 출시 직전 사용 중인 SDK 버전과 Google의 최신 데이터 공개 문서를 다시 대조합니다.

## 6. 데이터 공유/판매 관련 설명
- SignPDF 개발자가 사용자의 PDF/이미지 내용 또는 PDF 비밀번호를 광고주에게 판매하지 않습니다.
- 다만 AdMob SDK가 광고 제공, 분석 및 부정행위 방지 목적으로 위 데이터를 Google과 처리/공유할 수 있으므로 Data Safety에는 이를 반영합니다.

## 7. 계정 삭제
- SignPDF 자체 사용자 계정이 없으므로 앱 계정 삭제 기능 대상이 아닙니다.
- 앱 로컬 데이터는 최근 파일 항목 삭제 또는 Android의 앱 데이터 삭제를 통해 제거할 수 있습니다.

## 8. 타깃층 및 콘텐츠
- 특별히 어린이를 대상으로 제작한 앱이 아닙니다.
- PDF 문서 유틸리티/생산성 도구입니다.
- 폭력, 성적 콘텐츠, 도박 등 자체 콘텐츠를 제공하지 않습니다.
- 사용자가 직접 선택한 문서의 내용은 앱이 제공하는 자체 콘텐츠가 아닙니다.

실제 연령/콘텐츠 등급 설문은 Play Console의 최신 질문에 사실대로 답변합니다.

## 9. 권한 및 파일 접근
현재 매니페스트의 직접 권한:
- `INTERNET`
- `ACCESS_NETWORK_STATE`

광고/네트워크 기능에 사용합니다.

PDF/이미지 선택은 Android Storage Access Framework를 사용하므로 광범위한 저장소 권한을 직접 요청하지 않습니다.

## 10. 앱 기능 설명에서 사용할 수 있는 표현
- PDF에 손서명 추가
- PDF에 필기 및 형광펜 추가
- JPG/PNG/BMP/WEBP 이미지를 PDF로 변환
- 비밀번호가 설정된 PDF 열기(실기기 최종 테스트 통과 후 스토어 문구에 반영)
- 편집 결과를 새 PDF로 저장
- 다른 앱으로 PDF 공유

## 11. 사용하지 말아야 할 표현
- 공인전자서명
- 법적으로 인증된 전자서명
- 전자계약 인증 서비스
- 문서의 보안을 보장한다는 표현
- 지원하지 않는 DOC/DOCX 변환
- 암호화 기능을 제공한다고 과장하는 표현

SignPDF는 사용자가 소유하거나 접근 권한이 있는 암호 PDF의 비밀번호를 입력해 문서를 여는 기능을 제공하는 것이며, 비밀번호 우회/해제 도구로 홍보하지 않습니다.

## 12. 제출 직전 수동 확인 항목
- 실제 AdMob App ID/Banner ID 적용
- `signpdf_pro` 상품 생성·활성화
- 공개 HTTPS 개인정보처리방침 URL 입력
- Data Safety 답변과 실제 SDK 동작 일치 확인
- 앱 콘텐츠/광고/콘텐츠 등급 설문 완료
- 스토어 아이콘/기능 그래픽/스크린샷 등록
- 서명된 Play AAB 사용
- 정상 PDF와 암호 PDF 실기기 테스트 완료
