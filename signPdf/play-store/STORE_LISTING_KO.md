# SignPDF Google Play 스토어 등록정보 초안

## 앱 이름
SignPDF - PDF 서명·필기

## 짧은 설명
PDF에 서명하고 필기하며 이미지 변환과 다양한 PDF 도구를 이용하세요.

## 자세한 설명
SignPDF는 PDF 문서에 직접 서명하고 필기하고, 필요한 PDF 작업을 간편하게 처리할 수 있는 문서 도구입니다.

주요 기능
- PDF 파일 열기 및 페이지 보기
- 비밀번호가 설정된 PDF 열기
- 원하는 위치를 지정해 손서명 삽입
- 펜, 연필, 형광펜으로 필기
- 지우개, 실행 취소 및 다시 실행
- JPG, PNG, BMP, WEBP 이미지를 PDF로 변환
- 편집한 문서를 새 PDF로 저장하고 파일명 변경
- 저장한 PDF를 다른 앱으로 공유
- 최근 사용한 문서 빠르게 다시 열기
- 기본 PDF 저장 폴더 지정

무료 사용
- 핵심 PDF 열기·서명·필기 기능 제공
- 결과 PDF를 생성·저장하는 작업은 월간 주기당 10회 제공

광고 보상으로 60분 전체 기능
- 보상형 전면광고를 끝까지 시청하면 60분 동안 작업 횟수 제한 해제
- 60분 동안 배너 광고 숨김
- 서명 저장 및 재사용
- 여러 PDF 병합
- 페이지 순서 변경·회전·삭제
- 페이지 추출 및 PDF 분할
- 여러 이미지 일괄 변환과 용지 크기·여백·품질 설정
- 결제나 구독 없음

개인정보 보호
- 사용자가 연 PDF와 이미지는 기기에서 처리합니다.
- 문서 내용과 PDF 비밀번호는 서버로 올라가지 않습니다.
- 원본 문서는 변경하지 않고 편집 결과를 새 PDF로 저장합니다.

- Word 변환 지원이라고 표시하지 않기
- 문서 암호화 또는 보안 기능을 제공한다고 과장하지 않기
