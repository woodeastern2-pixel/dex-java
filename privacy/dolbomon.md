# 돌봄온 개인정보처리방침

최종 수정일: 2026-09-03

**앱:** 돌봄온 - 어르신 일상 기록과 보호자 소통  
**개발자:** Eastern Wood Studio  
**개인정보 문의:** woodeastern2@gmail.com

Eastern Wood Studio는 돌봄온 사용자의 개인정보를 중요하게 생각합니다. 본 개인정보처리방침은 돌봄온 앱에서 어떤 정보가 처리될 수 있고, 해당 정보가 어떻게 이용되는지 설명합니다.

## 1. 돌봄온의 기본 데이터 처리 방식

돌봄온은 자체 회원가입이나 개발자 운영 서버 없이 동작하는 로컬 중심의 **일상 기록 및 보호자 소통 도구**입니다.

사용자가 앱에 직접 입력하는 아래 정보는 기본적으로 사용자의 기기 내부에 저장됩니다.

- 어르신 이름, 나이, 호실, 메모
- 보호자 이름, 관계, 휴대전화번호, 이메일, 선호 연락수단
- 오늘 일정, 대화·교류, 생활 지원, 하루 분위기, 주요 활동, 공유 포인트 등 일상 기록
- 활동, 필요한 생활용품, 전달사항
- 사용자가 직접 입력한 추가 메모
- 앱에서 생성한 보호자 전달 문구
- 사용자가 촬영하거나 선택하여 일상 기록에 첨부한 사진

Eastern Wood Studio는 위 일상 기록 및 보호자 소통 데이터를 자체 서버로 전송하거나 저장하지 않습니다.

## 2. 일상 기록 및 보호자 소통 정보

돌봄온은 어르신의 하루 일정, 활동, 생활 지원, 필요한 생활용품과 보호자에게 전할 내용을 정리하기 위한 기능을 제공합니다.

사용자가 입력한 내용은 전달문을 만들거나 지난 일상 기록을 확인하는 데 사용됩니다. 앱이 작성한 전달문은 사용자가 내용을 확인하고 필요하면 직접 수정한 뒤 외부 공유 기능을 통해 전달할 수 있습니다.

돌봄온은 사용자가 입력한 일상 내용을 개발자 서버에서 분석하거나 외부 데이터베이스와 결합하지 않습니다.

## 3. 사진

일상 기록에 첨부한 사진은 일반 갤러리가 아닌 돌봄온의 앱 전용 저장공간에 보관하는 것을 기본으로 합니다.

사용자가 문자, 카카오톡, 이메일 또는 다른 앱으로 사진을 공유하기로 선택하면 해당 사진은 사용자가 선택한 외부 앱으로 전달됩니다. 외부 앱으로 전달된 이후의 정보 처리는 해당 서비스 제공자의 개인정보처리방침과 정책을 따릅니다.

## 4. 문자, 카카오톡, 이메일 및 다른 앱으로 공유

돌봄온은 사용자가 작성하거나 자동 생성한 전달 내용과 선택한 사진을 Android의 공유 기능을 이용하여 외부 앱으로 넘겨줍니다.

돌봄온이 사용자를 대신해 백그라운드에서 임의로 메시지를 발송하지 않습니다. 실제 수신자 선택 및 최종 전송은 문자 앱, 카카오톡, 이메일 앱 등 사용자가 선택한 외부 앱에서 이루어집니다.

돌봄온에 표시되는 전송 기록은 외부 앱의 전송 화면을 열었다는 사실을 기록하기 위한 것이며 상대방의 실제 수신 또는 읽음 여부를 의미하지 않습니다.

## 5. 음성 입력

사용자가 '말해서 기록' 기능을 선택할 경우 기기에 설치된 Android 음성 인식 서비스가 음성을 처리할 수 있습니다.

음성 인식 서비스의 네트워크 사용 여부 및 데이터 처리는 사용자의 기기와 선택한 음성 인식 서비스의 설정 및 정책에 따라 달라질 수 있습니다. Eastern Wood Studio는 음성 데이터를 자체 서버에 수집하거나 저장하지 않습니다.

## 6. 광고

돌봄온은 무료 서비스 운영을 위해 **Google Mobile Ads SDK(AdMob)**를 사용합니다.

광고 제공, 광고 측정, 빈도 관리, 분석 및 부정 사용 방지를 위해 Google 또는 광고 제공자가 다음과 같은 정보를 처리할 수 있습니다.

- IP 주소를 통해 추정되는 대략적인 위치
- 앱 실행, 광고 조회 및 광고와의 상호작용 정보
- 앱 실행 상태, 오류 및 성능 관련 진단 정보
- 광고 ID, 앱 세트 ID 등 기기 또는 기타 식별자

관련 법률 또는 사용자의 지역에 따라 개인정보 선택이 필요한 경우 Google User Messaging Platform(UMP)을 통해 동의 또는 개인정보 선택 화면이 제공될 수 있습니다.

**돌봄온은 어르신 이름, 사진, 보호자 연락처, 일상 기록, 생활용품, 전달사항 등의 내용을 광고 타겟팅 정보로 Google 또는 광고 제공자에게 전달하지 않습니다.**

## 7. 보안

돌봄온은 기기에 저장되는 정보를 보호하기 위해 다음과 같은 기능을 제공합니다.

- PIN 기반 앱 잠금
- 지원 기기에서 생체인증 잠금 해제
- 자동 잠금
- Android Keystore 기반 민감 문자열 암호화
- 앱 전용 사진 저장공간
- 최근 앱 화면 및 화면 캡처로 개인정보가 노출되는 것을 줄이기 위한 보호 설정

사용자의 기기 자체 보안 상태, 운영체제 설정 또는 외부 공유 앱의 보안 상태까지 Eastern Wood Studio가 통제할 수는 없습니다.

## 8. 암호화 백업 및 복원

사용자는 돌봄온 데이터를 백업 파일로 내보낼 수 있습니다. 백업 파일은 사용자가 지정한 비밀번호를 이용해 암호화되며 사용자가 직접 선택한 저장 위치에 저장됩니다.

Eastern Wood Studio는 백업 비밀번호를 수집하거나 보관하지 않습니다. 백업 비밀번호를 분실하면 개발자가 복구해 드릴 수 없습니다.

사용자가 백업 파일을 제3자 클라우드 저장소, 메신저 또는 다른 서비스에 보관하는 경우 그 이후의 정보 처리는 해당 서비스의 정책을 따릅니다.

## 9. 사용자 계정 및 개발자 서버

돌봄온은 기본 기능을 사용하기 위해 Eastern Wood Studio의 회원가입이나 자체 계정을 요구하지 않습니다.

현재 버전은 가족용 온라인 조회, 클라우드 동기화 또는 개발자 운영 서버에 일상 기록 데이터를 저장하는 기능을 제공하지 않습니다.

## 10. 데이터 삭제

사용자는 앱 설정의 **전체 데이터 삭제** 기능을 통해 기기에 저장된 어르신, 보호자, 일상 기록 및 사진을 삭제할 수 있습니다.

Android 설정에서 돌봄온의 앱 데이터를 삭제하거나 앱을 제거하는 방법으로도 로컬 데이터를 삭제할 수 있습니다.

Google 광고 서비스가 처리하는 데이터의 보관 및 삭제는 Google의 정책과 사용자의 Google 계정 및 광고 설정에 따릅니다.

Eastern Wood Studio는 사용자가 돌봄온에 입력한 어르신 정보, 보호자 연락처, 일상 기록 또는 사진을 판매하지 않습니다.

각 제3자 서비스가 처리하는 정보에는 해당 서비스 제공자의 개인정보처리방침 및 정책이 적용됩니다.
