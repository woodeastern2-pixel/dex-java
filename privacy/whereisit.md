# 내 물건 어디있지? 개인정보처리방침

최종 수정일: 2026-09-03

**개발자:** Eastern Wood Studio<br>
**개인정보 문의:** woodeastern2@gmail.com

Eastern Wood Studio는 **내 물건 어디있지?** 사용자의 개인정보 보호를 중요하게 생각합니다. 본 개인정보처리방침은 앱이 어떤 데이터를 처리하고 해당 데이터가 어떻게 사용되는지 설명합니다.

## 1. 사용자가 저장하는 물건 정보

앱은 사용자가 직접 입력한 다음 정보를 물건 찾기, 검색, 즐겨찾기 및 상세 보기 기능을 제공하기 위해 처리합니다.

- 물건 이름과 보관 위치
- 카테고리, 태그 및 메모
- 사용자가 직접 촬영하거나 선택한 사진
- 생성일, 수정일 및 즐겨찾기 상태

이 정보는 기본적으로 사용자의 기기 내부 앱 저장소에 보관됩니다. Eastern Wood Studio는 물건 정보나 사진을 자체 서버로 전송하거나 별도로 수집하지 않습니다.

사용자는 앱에서 물건을 삭제할 수 있습니다. 앱 데이터 삭제 또는 앱 제거 시 Android 운영체제의 동작에 따라 기기에 저장된 앱 데이터도 제거됩니다.

## 2. 카메라와 사진

카메라 권한은 사용자가 물건 사진 촬영 기능을 직접 선택했을 때만 요청합니다. 촬영한 사진은 앱 전용 저장소에 저장됩니다.

갤러리에서 사진을 선택하는 경우 Android의 시스템 문서 선택기를 사용합니다. 앱은 사용자가 선택한 사진에 대해서만 Android가 허용한 접근 권한을 사용합니다.

## 3. 광고

앱에는 **Google Mobile Ads SDK(AdMob)**가 포함됩니다. 광고 제공, 광고 측정, 빈도 관리, 분석 및 부정 사용 방지를 위해 Google 또는 광고 제공자가 다음과 같은 정보를 처리할 수 있습니다.

- IP 주소를 통해 추정되는 대략적인 위치
- 앱 실행, 탭 및 광고 조회 같은 앱·광고 상호작용
- 앱 실행 시간, 멈춤 현상 및 성능 같은 진단 정보
- 광고 ID, 앱 세트 ID 등 기기 또는 계정 식별자

관련 법률 또는 사용자의 지역에 따라 동의나 개인정보 선택이 필요한 경우 앱은 **Google User Messaging Platform(UMP)**을 이용해 개인정보 선택 화면을 제공합니다. 필요한 경우 앱 하단의 **광고 개인정보 설정**에서 선택을 다시 변경할 수 있습니다.

앱에는 유료 Pro 모드가 없으며 물건 등록, 검색, 사진, 즐겨찾기와 공유를 포함한 핵심 기능을 광고 시청 없이 이용할 수 있습니다. 자동 전면광고는 표시하지 않습니다. 사용자가 홈 화면에서 보상형 전면광고 시청을 명시적으로 선택하고 광고를 끝까지 시청하면, 완료 시점부터 60분 동안 배너 광고가 표시되지 않습니다. 이 보상 이용 종료 시각은 사용자의 기기 내부에만 저장됩니다.

## 4. Android 백업

사용자가 Android 기기의 백업 기능을 활성화한 경우 물건 데이터, 앱이 촬영한 사진 및 앱 설정이 Android의 암호화된 백업 또는 기기 간 전송 대상에 포함될 수 있습니다. 백업의 보관과 처리는 사용자의 Android 계정 및 기기 설정과 Google의 정책을 따릅니다.

## 5. 사용자 계정 및 데이터 판매

앱은 자체 회원가입 또는 사용자 계정 생성을 요구하지 않습니다. Eastern Wood Studio는 사용자가 앱에 저장한 물건 정보나 사진을 판매하지 않습니다.

## 6. 데이터 보안

앱이 자체적으로 저장하는 물건 정보와 사진은 사용자의 기기 내부에 보관됩니다. 광고 SDK가 전송하는 정보는 해당 서비스 제공자의 보안 정책이 적용됩니다.

사용자는 화면 잠금, 기기 암호화 등 Android가 제공하는 보안 기능을 사용하여 기기를 보호하는 것이 좋습니다. 인터넷 또는 전자 저장 방식은 완전한 보안을 보장할 수 없으므로 절대적인 보안을 보장할 수는 없습니다.

## 7. 아동의 개인정보

앱은 아동을 주 대상으로 설계되지 않았습니다. Eastern Wood Studio는 고의적으로 아동의 개인정보를 자체 서버에 수집하지 않습니다.

## 8. 제3자 서비스

앱은 기능 및 수익화를 위해 다음과 같은 제3자 서비스를 사용합니다.

- Google Play 서비스
- Google Mobile Ads
- Google User Messaging Platform

이러한 서비스에서 처리하는 정보에는 각 서비스 제공자의 개인정보처리방침과 정책이 적용됩니다.

## 9. 개인정보처리방침 변경

앱 기능, 광고 또는 데이터 처리 방식이 변경되는 경우 본 개인정보처리방침도 변경될 수 있습니다. 중요한 변경 사항이 있는 경우 본 페이지의 최종 수정일을 갱신합니다.
