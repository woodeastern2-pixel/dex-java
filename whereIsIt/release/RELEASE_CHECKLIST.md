## 광고·보상 정책

- 배너: 메인 화면 하단의 anchored adaptive banner 1개
- 보상형 전면광고: 홈 화면에서 사용자가 **광고 시청**을 명시적으로 선택한 경우에만 표시
- 보상: 시청 완료 시점부터 정확히 60분 동안 배너 광고 제거
- 미노출 지점: 앱 시작, 상세 화면 복귀, 물건 입력·수정·저장, 카메라·갤러리 전환

## 상용 광고 ID

- 앱: `ca-app-pub-9360550840761530~8809407191`
- 배너: `ca-app-pub-9360550840761530/8722766965`
- 60분 보상형 전면광고: `ca-app-pub-9360550840761530/7837060708`

광고 ID는 공개 식별자이므로 릴리스 워크플로 환경값에 명시합니다. Play 업로드 서명 정보만 GitHub Actions 저장소 비밀값으로 관리합니다.

## Play 업로드 서명 비밀값

1. `WHEREISIT_KEYSTORE_BASE64`
2. `WHEREISIT_KEYSTORE_PASSWORD`
3. `WHEREISIT_KEY_ALIAS`
4. `WHEREISIT_KEY_PASSWORD`

그 후 **Release WhereIsIt** 워크플로를 수동 실행합니다. 이 워크플로는 실제 광고 ID와 Play 업로드 서명을 검증한 뒤 production APK/AAB와 release lint 결과를 생성합니다.

## 산출물의 구분

- QA APK: 설치·기능 검증용이며 Google 공식 테스트 광고 ID 사용
- CI production AAB: 실제 광고 ID가 적용된 미서명 번들이며 로컬의 전용 업로드 키로만 서명
- Production APK/AAB: 업로드 서명 비밀값이 모두 등록된 **Release WhereIsIt** 워크플로에서도 생성 가능

테스트 광고 ID가 포함된 QA 산출물은 수익화용으로 게시하지 않습니다.
