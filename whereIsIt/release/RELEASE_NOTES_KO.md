# 내 물건 어디있지? 1.2.0 출시 노트

- 사진이 없는 물건은 더 간결한 목록으로, 사진이 있는 물건은 사진이 먼저 보이도록 화면을 개선했습니다.
- 큰 글자 설정에서도 카테고리, 태그, 메모 안내가 겹치지 않도록 입력 화면을 개선했습니다.
- 카메라 촬영이 중단되는 문제를 수정하고 예외 상황 안내를 보강했습니다.
- 앱 아이콘의 크기와 Android 테마 아이콘 표시를 다듬었습니다.
- 검색, 즐겨찾기와 카테고리 필터를 이용해 물건을 더 빠르게 찾을 수 있습니다.
- 개인정보 동의와 광고 설정을 제공하고, 작업을 방해하지 않는 간격으로 광고를 표시합니다.
