# Google Play 데이터 보안 작성안

대상 버전: `1.3.0 (versionCode 6)`<br>
작성 기준일: 2026-09-03

이 문서는 Play Console의 데이터 보안 설문 입력을 돕기 위한 초안입니다. 최종 제출 전 실제 AdMob 설정, 선택한 광고 기능 및 당시 Google Mobile Ads SDK 공개 문서를 다시 확인해야 합니다.

## 1. 앱 자체 데이터 처리

| 질문 | 권장 응답 | 근거 |
|---|---|---|
| 자체 계정 생성 | 아니요 | 회원가입·로그인 기능 없음 |
| 물건 이름·위치·메모·태그 수집 | 앱 서버 수집 아님 | Room DB를 이용해 기기 내부에 저장 |
| 사용자가 선택한 사진 수집 | 앱 서버 수집 아님 | 앱 전용 저장소 또는 시스템 선택기 URI로 기기에서 사용 |
| 데이터 삭제 요청 | 앱 내 삭제 가능 | 개별 물건 삭제 및 앱 데이터 삭제/앱 제거 지원 |
| 전송 중 암호화 | 예 | 광고 SDK 전송은 TLS 사용. 앱 자체 서버 전송 없음 |

Android 백업이 활성화된 사용자의 물건 데이터, 앱 촬영 사진 및 설정은 암호화된 Android 백업 또는 기기 간 전송 대상이 될 수 있습니다. 이 동작은 개인정보처리방침에도 공개합니다.

## 2. Google Mobile Ads SDK 공개 대상

Google의 SDK 공개 문서를 기준으로 다음 데이터 유형을 광고 제공, 분석 및 부정 사용 방지 목적으로 수집·공유하는 항목으로 검토합니다.

| Play 데이터 유형 | 앱에서의 공개 대상 | 용도 |
|---|---|---|
| 대략적인 위치 | IP 주소에서 추정될 수 있음 | 광고, 분석, 부정 사용 방지 |
| 앱 상호작용 | 앱 실행, 탭, 광고 조회 등 | 광고, 분석, 부정 사용 방지 |
| 진단 | 앱 실행 시간, 멈춤 현상, 성능·에너지 사용 등 | 분석, 부정 사용 방지 |
| 기기 또는 기타 ID | 광고 ID, 앱 세트 ID 등 | 광고, 분석, 부정 사용 방지 |

광고 관련 데이터는 Google Mobile Ads SDK가 자동 처리할 수 있으며 전송 중 TLS로 암호화됩니다. 광고 ID 사용 여부와 제한 광고 동작은 사용자의 Android 설정, 동의 상태 및 AdMob 구성에 따라 달라질 수 있습니다.

## 3. 개인정보 동의

- 앱 시작 시마다 UMP의 동의 정보를 갱신합니다.
- 동의가 필요한 지역에서는 필요한 양식을 표시합니다.
- `canRequestAds()`가 참인 경우에만 Mobile Ads SDK를 초기화하고 광고를 요청합니다.
- UMP가 개인정보 옵션 진입점을 요구하는 경우 메인 화면에 **광고 개인정보 설정** 버튼을 표시합니다.
- 보상형 전면광고 시청 완료 시 60분 광고 제거 종료 시각을 기기 내부 설정에만 저장합니다.

## 4. Play Console 제출 전 확인

1. 실제 AdMob 계정에서 사용하는 광고 기능과 미디에이션 파트너를 확인합니다.
2. 미디에이션을 추가했다면 각 파트너 SDK의 데이터 공개 내용을 합산합니다.
3. AdMob SDK 또는 앱 기능이 변경되면 설문을 다시 검토합니다.
4. Play Console의 앱 콘텐츠, 광고 포함 여부 및 개인정보처리방침 URL을 입력합니다.
5. 스토어 등록정보에서 **광고 포함**을 `예`로 표시합니다.
