# 돌봄온 (DolbomOn)

요양원·요양병원·돌봄 현장에서 간병인/요양보호사가 어르신의 하루를 빠르게 기록하고 보호자에게 공유하기 위한 Android 앱입니다.

## 현재 버전
- 앱 이름: 돌봄온
- 패키지: `com.easternwood.dolbomon`
- 버전: `0.4.0` (versionCode 17)
- Android: minSdk 24 / targetSdk 36
- 자체 서버 및 회원가입 없음
- 주요 데이터는 기기 내부 암호화 저장
- 한국어 / English / 中文 / Tiếng Việt
- 첫 실행 기본 언어: 한국어
- 수익화: 무료 + AdMob 배너 광고

## v0.4.0 리디자인 정합성/공통 버튼 보완
- 승인된 리디자인 시안을 다시 기준으로 홈·상세·기록·추가 기록·전달·지난 기록·설정 화면의 패딩, 카드 높이, 여백, 테두리, 내비게이션 밀도를 재조정
- `secondaryButton`, `softButton`, `compactButton` 등 공통 버튼을 완전한 외곽선 배경으로 통일해 삼성 기기 등에서 버튼 하단선이 흐려지거나 사라져 보이는 문제를 구조적으로 보완
- 카드/컨트롤 테두리와 구분선 색 대비를 높이고 선택 Chip과 설정 행 높이를 리디자인 시안에 가깝게 조정
- 홈 환영 영역에 돌봄 제공자와 어르신을 표현하는 전용 일러스트를 추가하고 대시보드/어르신 목록/추가 버튼의 크기와 간격을 재정렬
- 상세 화면 프로필 카드, 오늘 기록 버튼, 2x3 빠른 기능 카드 및 보호자 영역의 세로 밀도를 조정
- 오늘 상태의 식사·수분·컨디션·기분·수면·배변 각 행에 시각 표식을 추가하고 행 높이, Chip 높이, 좌우 간격을 확대
- 추가 기록의 활동·필요물품·특이사항·추가 메모·사진 영역과 전달문 화면 버튼/구분선의 외곽선 표현을 강화
- Android 15(API 35)에서 전체 디자인 화면 캡처 성공, 기존 기록 선택/단계 전환 회귀 테스트 성공, Release Lint 및 Play용 AAB 빌드 성공

## v0.3.9 전달 대기함/실기기 UI 보완
- 홈 우측 상단 종 버튼의 임시 `돌봄온` Toast 제거
- 종 버튼과 하단 `메시지` 탭을 새 `전달 대기함` 화면으로 연결
- 기록은 저장했지만 아직 보호자에게 보내지 않은 전달문을 어르신별·기록별로 모두 모아 표시
- 여러 어르신의 미전달 전달문이 동시에 있어도 각각 별도 카드로 유지하고 `내용 확인`으로 해당 전달문을 다시 열어 수정·전달 가능
- 보호자 전달이 완료된 기록은 전달 대기함에서 제외하고 지난 기록에서 계속 확인
- 홈의 `전달 대기` 수치도 오늘 한 명의 마지막 기록이 아니라 전체 미전달 전달문 수와 일치하도록 변경
- 저장된 특정 전달문을 `record_id`로 다시 열어 다른 어르신의 전달문과 섞이지 않도록 개선
- 사진 찍기 / 사진 선택 버튼 아래 구분선을 2dp로 강화
- 전달문 생성 화면의 `상세 보기` / `지난 기록`을 명시적인 외곽선 카드 버튼으로 변경하고 하단 구분선 추가

- 오늘 상태의 식사·수분·컨디션·기분·수면·배변 행 높이와 상하 여백, Chip 높이/간격을 확대해 리디자인 시안에 가깝게 조정

- 전달문 생성 화면에서 `상세 보기` / `지난 기록`으로 바로 이동할 수 있는 버튼 추가

## 핵심 기능
- 어르신 및 여러 보호자 등록
- 식사, 수분, 컨디션, 기분, 수면, 배변, 활동, 특이사항을 버튼으로 기록
- 체크 결과를 자연스러운 보호자 전달 문장으로 자동 생성
- 필요물품 수량·긴급도 기록 및 문장 자동 반영
- 사진 촬영/첨부 및 앱 전용 저장공간 보관
- 음성 입력과 자주 쓰는 문구
- 문자, 카카오톡, 이메일 및 Android 공유로 전달
- 보호자 다중 선택 후 순차 공유
- 미전달 전달문 통합 관리 및 개별 재진입
- 날짜별 기록, 사진 앨범, 최근 7일 돌봄앨범 공유
- PIN/생체인증/자동 잠금 및 개인정보 보호
- 암호화 백업/복원, 전체 데이터 삭제
- 앱 내 개인정보처리방침

## 화면 녹화 정책
- Debug APK: 실기기 UI 검수와 테스트 영상 공유를 위해 화면 녹화/스크린샷을 허용합니다.
- Release AAB: 어르신 정보와 사진 보호를 위해 화면 캡처/녹화 방지(FLAG_SECURE)를 유지합니다.

## 소스 보관 형식
현재 연결된 GitHub 쓰기 환경이 UTF-8 텍스트 파일 쓰기만 안정적으로 지원하므로 전체 Android 소스는 분할된 `source.tar.gz.b64.part-*`에 압축·Base64 형태로 보관합니다. CI에서 자동으로 합쳐 정상 Gradle 프로젝트로 빌드합니다.

확정된 밝은 하늘색 돌봄온 아이콘 원본도 압축된 프로젝트 내부 `app/icon-source.b64`에 포함되어 있으며, 빌드 시 실제 런처 PNG로 생성됩니다.
