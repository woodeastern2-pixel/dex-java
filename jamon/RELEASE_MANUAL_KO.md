# 잠온 Google Play 출시 매뉴얼

이 문서는 `dex-java` 저장소의 잠온 앱을 기존 Google Play 앱과 같은 신원으로 안전하게 출시하기 위한 단일 기준 문서다. 이전 출시 과정에서 확인한 패키지명, 업로드 인증서, 버전 규칙, 사용자 검수 방식과 현재 소스 상태를 함께 반영한다.

## 1. 출시 원칙

다음 다섯 가지는 예외 없이 지킨다.

1. 기존 앱을 새 프로젝트나 새 패키지로 다시 만들지 않는다. `dex-java/jamon`을 계속 수정한다.
2. Google Play에 올렸던 앱과 패키지명 및 업로드 인증서가 정확히 같아야 한다.
3. 소스, 서명 키, 버전, 디자인 기준을 확인하지 않은 AAB는 만들거나 업로드하지 않는다.
4. Galaxy S26 Ultra에서 승인된 시안과 실제 동작을 끝까지 검수한 빌드만 출시 후보로 지정한다.
5. 오류가 난 빌드를 반복 업로드하지 않는다. 원인을 고치고 검증 기록을 남긴 뒤 한 번만 다시 올린다.

## 2. 현재 출시 신원

아래 값이 하나라도 다르면 기존 앱의 업데이트로 출시할 수 없다.

| 항목 | 잠온 기준값 | 현재 상태 |
|---|---|---|
| Play 앱 이름 | 잠온 - 수면 루틴과 수면 사운드 | 확인됨 |
| 기본 언어 | 한국어 `ko-KR` | 확인됨 |
| Application ID | `com.easternwood.sleeproutine` | 확인됨 |
| 현재 출시 버전 | `0.8.0` | 확인됨 |
| 다음 versionCode | `12` 이상 | 소스는 `12` |
| compileSdk / targetSdk | `36 / 36` | 확인됨 |
| minSdk | `26` | 확인됨 |
| 업로드 키 별칭 | `Jamon Upload` | 출시 환경에서 재확인 필요 |
| 업로드 인증서 SHA-1 | `12:90:5E:46:9C:D1:3F:66:40:42:8B:11:77:F9:C1:97:67:7B:46:76` | 검증 스크립트에 고정됨 |
| 업로드 인증서 SHA-256 | `33:5A:8C:D6:A3:DA:FB:A4:6A:48:7B:20:13:F1:B2:17:A0:4B:EA:E3:FD:97:B3:52:F8:D7:3C:A1:E3:DB:9C:AF` | 검증 스크립트에 고정됨 |

AdMob 출시 신원은 다음 값으로 고정한다.

| 항목 | 출시값 |
|---|---|
| AdMob 앱 ID | `ca-app-pub-9360550840761530~2835130981` |
| 홈 배너 광고 단위 | `ca-app-pub-9360550840761530/6726274534` |
| 24시간 Pro 보상형 광고 단위 | `ca-app-pub-9360550840761530/1522049310` |

`play-store/app-ads.txt`는 스토어 등록정보에 입력한 개발자 웹사이트 도메인의 루트 `/app-ads.txt`에 동일한 내용으로 공개한다.

주의: 디버그 APK의 패키지명은 `.debug`가 붙고 인증서도 다르다. 디버그 APK는 기기 검수용일 뿐 Play 업로드용이 아니다.

| 서명된 release AAB | 미생성 | 위 차단 항목 해결 후 생성 |

## 4. Gate 0 — 상품 모델부터 일치시키기

확정 상품 모델은 **Billing 없는 무료 앱 + 선택형 보상광고 기반 24시간 Pro**다.

- 백그라운드 재생과 1~720분 루틴 시간은 무료·Pro 모두 제공한다.
- 무료 모드는 기본 사운드 5종과 최대 2개 조합을 제공한다.
- 사용자가 보상형 광고를 직접 선택해 끝까지 시청하면 Pro 8종을 포함한 전체 13종과 최대 4개 조합을 24시간 제공한다.
- Pro 만료 시각은 기기에 저장하며 앱 재실행 후에도 유지한다.
- 재생 중 Pro가 만료되어도 현재 수면 루틴은 중단하지 않고 다음 루틴부터 무료 제한을 적용한다.
- 홈 탐색 화면의 배너는 무료 상태에서만 표시한다.
- 수면 세션 시작 이후, 화면 꺼짐, 백그라운드 재생, 루틴 종료, 뒤로가기에는 광고를 표시하지 않는다.
- 구매, 구독, 가격, 구매 복원과 Google Play Billing은 사용하지 않는다.
- 검수용 Pro 스위치는 정식 UI와 release 코드에서 제거한다.

**Go 조건:** 앱 화면, 코드, Play Console 선언, 스토어 문구가 하나의 상품 모델로 완전히 일치한다.

## 5. Gate 1 — 출시 전 코드 정리

제가 다음 순서로 처리한다.

- 검수 전용 기능과 문구를 release 소스에서 제거한다.
- `ProActivity`, `Prefs.isPro`, Pro 잠금 분기를 24시간 보상 만료 시각 하나로 통일한다.
- 앱 이름, 패키지명, 버전, 아이콘, 언어 리소스가 release 변형에 정확히 적용되는지 확인한다.
- `debuggable=false`, `.debug` 접미사 없음, 테스트 문구·테스트 광고 ID·검수 스위치 없음 상태를 확인한다.
- 릴리스 의존성, 병합 Manifest, 권한을 다시 검사한다.
- 코드 수정 전후를 Git 커밋으로 보존하고 강제 초기화나 소스 삭제를 하지 않는다.

## 6. Gate 2 — 개인정보·정책 문서

수면 기록과 앱 설정은 기기 내부에만 저장되지만, 광고 표시를 위해 Google Mobile Ads SDK와 UMP가 네트워크를 사용한다. 개인정보처리방침에는 최소한 아래 내용을 명시한다.

- 수면 기록, 선택 사운드, 루틴 시간, 언어 설정이 기기에만 저장된다는 사실
- Google 광고 SDK가 광고 제공, 측정, 부정행위 방지를 위해 처리하는 데이터와 Google 정책 링크
- UMP 동의 화면과 앱 설정의 `광고 개인정보 설정`에서 선택사항을 관리하는 방법
- 알림 권한은 백그라운드 재생 알림과 정지 제어에 사용된다는 사실
- 회원가입이나 계정 삭제 절차가 없다는 사실
- 앱 설정의 기록 삭제 또는 앱 삭제로 로컬 데이터를 삭제할 수 있다는 사실
- 문의 이메일, 시행일, 정책 변경 안내 방식

한국어·영어 통합 개인정보처리방침은 `privacy/jamon.md`에 작성한다. 앱 설정의 `개인정보처리방침`과 Play Console은 로그인 없이 열리는 동일한 공개 주소를 사용한다.

현재 확정 주소: `https://github.com/woodeastern2-pixel/dex-java/blob/main/privacy/jamon.md`

이 주소는 공개 저장소에서 비로그인 상태로 열리는 것을 확인했다. 방침 변경은 `main` 브랜치에 반영된 뒤 앱과 Play Console 양쪽에서 다시 연다.

Play Console의 Data safety는 최종 release AAB와 Google Mobile Ads SDK의 최신 데이터 공개 문서를 대조해 작성한다. 광고 SDK가 포함됐으므로 `데이터 수집 안 함`으로 제출해서는 안 된다.

## 7. Gate 3 — 권한과 Play Console 앱 콘텐츠

| 콘솔 항목 | 잠온 입력 원칙 |
|---|---|
| 앱 액세스 | 로그인·제한 계정 없음. 검수자는 보상형 테스트 흐름으로 Pro를 열 수 있음 |
| 광고 | Google Mobile Ads 배너·보상형 광고가 있으므로 `예` |
| 대상 연령 | 어린이용으로 설계하지 않은 일반 성인 웰니스 앱으로 설정. 실제 목표 연령은 최종 승인 필요 |
| 콘텐츠 등급 | 폭력, 도박, 사용자 생성 콘텐츠, 소셜 기능이 없다는 실제 동작 기준으로 IARC 작성 |
| 건강 앱 선언 | 수면 루틴·휴식을 돕는 웰니스/수면 관리. 진단·치료·의료 조언 및 Health Connect 사용 없음 |
| 포그라운드 서비스 | `mediaPlayback`만 선언. 사용자가 시작한 수면 사운드를 화면 꺼짐·백그라운드에서도 재생하고 알림에서 중지 |
| 알림 권한 | Android 13 이상에서 재생 알림을 위해 요청. 거부 시 동작과 안내를 실제 기기에서 검수 |
| 개인정보처리방침 | 앱 내 링크와 Play Console URL을 동일하게 입력 |

포그라운드 서비스 선언에 시연 영상이 요구되면 다음 장면을 한 영상에 담는다: 사용자가 루틴 시작 → 사운드 재생 → 홈 이동 또는 화면 끄기 → 지속 재생 → 상시 알림에서 정지.

## 8. Gate 4 — 음원 권리 증빙

앱 설정의 출처 표기만으로 끝내지 않는다. 각 음원마다 다음 표를 완성하고 원본 증빙을 보존한다.

| 필수 항목 | 예시 |
|---|---|
| 앱 내 사운드 키와 파일명 | `rain` / 실제 raw 파일 |
| 표시 이름 | 포근한 갈색소음, 창가의 잔잔한 비 등 |
| 출처 URL과 자산 ID | Freesound, Wikimedia 등 원본 페이지 |
| 저작자 | 원본 게시자명 |
| 라이선스 | CC0, CC BY 3.0, CC BY 4.0 등 정확한 버전 |
| 수정 내용 | 잘라내기, 반복, 음량 보정 여부 |
| 표시 문구 | 앱 내 실제 크레딧 |
| 증빙 | 다운로드 날짜의 라이선스 페이지 PDF 또는 캡처 |

상업 이용과 재배포가 허용되는지 확인하고, CC BY 음원은 저작자·제목·출처·라이선스를 빠짐없이 표시한다. 출처가 불명확한 음원은 출시 번들에서 제외하거나 권리가 명확한 음원으로 교체한다.

## 9. Gate 5 — Galaxy S26 Ultra 최종 검수

사용자께서 지정한 Galaxy S26 Ultra를 디자인과 동작의 기준 기기로 사용한다. 최종 release 후보와 동일한 코드의 APK로 아래를 모두 확인한다.

### 설치와 화면

- 기존 검수 APK 위에 업데이트 설치가 되고 기록·설정이 유지된다.
- 새로 설치했을 때 첫 화면, 권한 요청, 기본 언어가 정상이다.
- 홈, 사운드 조합, 라이브러리, 설정, 재생 화면이 승인 시안과 일치한다.
- 톱니바퀴, 상태 아이콘, 앱 아이콘이 찌그러지거나 작지 않다.
- 배경 이미지와 사운드 이미지가 조잡한 도형으로 대체되지 않는다.
- 작은 글자, 잘림, 겹침, 과도한 둥근 카드·테두리가 없다.

### 상태와 내비게이션

- 한국어↔English 변경 후 설정 화면에 그대로 남는다.
- 언어를 바꿔도 기록, 루틴 시간, 선택 사운드가 유지된다.
- 뒤로가기와 각 화면 이동이 홈으로 임의 초기화되지 않는다.
- 앱을 종료했다 다시 열어도 사용자 설정이 유지된다.

### 루틴 시간

- 숫자 직접 입력이 가능하다.
- 위·아래 버튼으로 1분씩 증감할 수 있다.
- 세로 휠을 올리고 내려 변경할 수 있다.
- `1, 7, 30, 31, 90, 720분`을 각각 설정하고 재실행 후 유지되는지 확인한다.
- 허용 범위를 벗어나는 값과 빈 입력이 안전하게 처리된다.
- 실제 수면 세션의 종료 시간이 설정값과 일치한다.

### 사운드와 백그라운드 동작

- 13개 사운드가 모두 미리듣기·선택·재생된다.
- 최대 4개 사운드 조합과 개별 음량 조절이 정확히 반영된다.
- 재생, 일시정지, 재개, 자동 종료, 수동 종료가 정상이다.
- 홈 이동, 화면 끄기, 앱 전환 후에도 재생이 유지된다.
- 알림 허용/거부 양쪽에서 크래시가 없고 안내가 자연스럽다.
- 알림의 정지 동작이 즉시 서비스와 오디오를 종료한다.
- 종료된 루틴이 주간 기록에 정확히 반영된다.

### 광고와 24시간 Pro

- 디버그 APK는 Google 공식 테스트 광고 ID만 사용한다.
- 무료 상태의 홈 하단에서만 배너가 표시된다.
- 보상형 광고를 끝까지 시청한 경우에만 Pro가 열린다.
- 광고를 중간에 닫거나 로드·표시가 실패하면 Pro가 열리지 않는다.
- 보상 후 정확히 24시간이 저장되고 앱 종료·재부팅 후에도 남은 시간이 유지된다.
- Pro 상태에서는 홈 배너가 사라지고 13종·4개 조합이 열린다.
- Pro 만료 후 다음 루틴부터 5종·2개 제한으로 돌아간다.
- Pro 만료 시 이미 재생 중인 루틴과 백그라운드 오디오는 끊기지 않는다.
- 수면 세션, 화면 꺼짐, 앱 전환, 루틴 종료에는 광고가 표시되지 않는다.
- 광고 동의를 거부하거나 광고가 없는 상태에서도 무료 기능과 백그라운드 재생은 정상 작동한다.

### 품질

- 크래시, ANR, 무음, 중복 재생, 메모리 급증이 없다.
- Android 16 및 최신 One UI에서 상태바·내비게이션바·백 제스처가 정상이다.
- 녹화 영상과 스크린샷을 출시 증빙 폴더에 남긴다.

## 10. Gate 6 — 스토어 등록정보

제가 앱과 동일한 모습으로 다음 자산을 만든다.

- 512×512 Play 스토어 아이콘
- 1024×500 피처 그래픽
- Galaxy S26 Ultra 실제 화면 기반 휴대전화 스크린샷
- 한국어 기본 등록정보와 영어 번역
- 짧은 설명, 상세 설명, 개인정보처리방침 URL, 문의 이메일
- 버전 `0.8.0` 출시 노트

스크린샷에는 실제 앱에 없는 기능, 결제, 광고 제거, 의료 효과를 넣지 않는다. `숙면을 보장`, `불면증 치료` 같은 표현도 사용하지 않는다.

### 출시 노트 초안

> 밤의 상태에 맞춘 수면 루틴과 13가지 수면 사운드를 새롭게 구성했습니다. 달빛 분위기의 화면과 상태 아이콘을 개선하고, 1분부터 12시간까지 자유롭게 설정하는 루틴 시간, 여러 환경음 조합과 개별 음량 조절, 화면이 꺼져도 이어지는 백그라운드 재생, 한국어·영어 및 수면 기록을 지원합니다.

## 11. Gate 7 — 서명된 AAB 생성과 기계 검증

서명 키는 저장소나 채팅에 올리지 않고 보안 환경 변수로만 연결한다.

```bash
export JAMON_KEYSTORE_PATH='/secure/path/jamon-upload.jks'
export JAMON_KEYSTORE_PASSWORD='***'
export JAMON_KEY_ALIAS='Jamon Upload'
export JAMON_KEY_PASSWORD='***'
```

비밀번호를 화면에 출력하거나 Git에 커밋하지 않는다. 먼저 업로드 인증서를 검사한다.

```bash
cd jamon
./scripts/verify_upload_keystore.sh
```

검증이 성공한 경우에만 정식 빌드를 실행한다. AGP `8.10.1`, Java 17과 호환되는 고정 Gradle 환경을 사용하고, 릴리스 도중 도구 버전을 임의로 올리지 않는다.

```bash
gradle -p . clean :app:lintRelease :app:testReleaseUnitTest :app:bundleRelease --no-daemon
```

빌드 결과는 `app/build/outputs/bundle/release/app-release.aab`여야 한다. 다음 항목을 자동 확인한다.

- AAB ZIP 무결성과 `bundletool validate`
- 패키지명 `com.easternwood.sleeproutine`
- `versionCode 12`, `versionName 0.8.0`
- release 빌드가 debuggable이 아님
- 업로드 인증서 SHA-1/SHA-256 정확히 일치
- Manifest 권한과 `mediaPlayback` 서비스 선언
- `.debug`, 검수 토글, 개발 문구, 테스트 SDK가 없음
- release에는 잠온 실제 AdMob ID 3개, debug에는 Google 테스트 ID만 포함됨
- Google Play Billing 의존성·구매·구독 코드가 없음
- 네이티브 `.so`가 없음을 확인. 현재 순수 Java/리소스 앱이므로 64비트·16KB 네이티브 페이지 정렬은 해당 없음
- AAB SHA-256 체크섬 생성

```bash
unzip -t app/build/outputs/bundle/release/app-release.aab
jarsigner -verify -verbose -certs app/build/outputs/bundle/release/app-release.aab
sha256sum app/build/outputs/bundle/release/app-release.aab
```

`bundletool`로 AAB에서 설치 APK를 생성하여 Galaxy S26 Ultra에서 한 번 더 전체 검수를 수행한다. 디버그 APK가 통과했더라도 release AAB 기반 설치 검수 전에는 업로드하지 않는다.

## 12. Gate 8 — Play Console 제출

1. Play Console 대시보드의 `프로덕션 액세스` 상태를 먼저 확인한다.
2. 조직 계정 전환 여부와 별개로 콘솔에 테스트 요구가 남아 있으면 그 요구를 따른다.
3. App content의 개인정보, Data safety, 광고, 앱 액세스, 대상 연령, 콘텐츠 등급, 건강 앱, 포그라운드 서비스 항목을 모두 완료한다.
4. 국가/지역, 가격(무료), 스토어 등록정보와 그래픽을 검토한다.
5. `관리형 게시`를 켜서 심사 승인 즉시 자동 공개되지 않도록 한다.
6. 내부 테스트에 동일 AAB를 먼저 올리고 설치·업데이트·결제 없는 전체 흐름을 확인한다.
7. 사전 출시 보고서의 크래시, ANR, 접근성, 보안 경고를 처리한다.
8. 프로덕션 릴리스를 만들고 버전과 서명, 변경사항을 마지막으로 확인해 심사에 제출한다.
9. 승인 후 사용자께서 공개 시점을 확인한 다음 관리형 게시에서 공개한다.

개인 개발자 계정의 12명·14일 비공개 테스트 규칙은 계정 생성 시기와 프로덕션 액세스 상태에 따라 적용된다. 조직 계정으로 전환했더라도 추측하지 않고 Play Console에 실제로 표시되는 요구사항을 최종 기준으로 삼는다.

## 13. 출시 후 운영

- 최초 공개 직후 Play Console Android vitals의 크래시율과 ANR을 확인한다.
- 사용자 리뷰에서 재생 중단, 알림, 음량, 시간 설정, 언어 문제를 우선 분류한다.
- 업데이트 출시부터는 가능하면 `5~10% → 25% → 50% → 100%` 단계 배포를 사용한다.
- 이상 징후가 있으면 단계 배포를 중지하고, 같은 versionCode의 AAB를 다시 만들지 않는다. 수정 후 versionCode를 올린다.
- 출시 AAB, SHA-256, Git 커밋·태그, 스크린샷, 검수 영상, 콘솔 선언 사본을 한 묶음으로 보관한다.

## 15. 최종 Go/No-go 체크리스트

아래 항목이 모두 체크되기 전에는 프로덕션에 제출하지 않는다.

- [ ] Billing 없는 24시간 보상형 Pro 모델과 앱 기능·문구가 일치한다.
- [ ] 검수용 토글과 개발용 UI가 release에서 완전히 제거됐다.
- [ ] 실제 AdMob ID는 release에만, Google 테스트 ID는 debug에만 포함됐다.
- [ ] 보상 완료·중도 종료·실패·24시간 만료 테스트를 통과했다.
- [ ] 개인정보처리방침이 앱과 Play Console에서 열린다.
- [ ] Data safety와 광고 선언이 최종 코드와 일치한다.
- [ ] 건강 앱 및 포그라운드 서비스 선언이 완료됐다.
- [ ] 모든 음원의 상업 이용 권리와 표시 의무가 증빙됐다.
- [ ] Galaxy S26 Ultra 전체 회귀 테스트를 통과했다.
- [ ] 스토어 그래픽과 설명이 실제 앱과 일치한다.
- [ ] 패키지명, versionCode, versionName이 정확하다.
- [ ] 업로드 인증서 두 지문이 기존 Play 앱과 일치한다.
- [ ] release AAB 기반 설치 테스트를 통과했다.
- [ ] lint, 테스트, 사전 출시 보고서의 차단 문제가 없다.
- [ ] AAB 체크섬, 커밋, 태그, 검수 증빙이 보관됐다.
- [ ] 관리형 게시가 켜져 있고 공개 시점이 승인됐다.
