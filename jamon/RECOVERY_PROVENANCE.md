# Recovery provenance

This project is a clean rebuild of the Jamon Android application reconstructed
from the project owner's installable `v0.7.0-debug` APK because the original
source repository was not present in the workspace or connected GitHub account.

Preserved product contracts:

- package and Android component behaviour
- 10 mood-based routine presets
- 1–720 minute session duration
- 13 bundled ambience tracks and their credits
- free/Pro mix limits, review toggle and local history
- Korean/English locale support and background playback

Intentionally replaced UI:

- stacked rounded cards and outlined pills
- repeated application icons used as sound artwork
- dense boxed controls and decorative borders

The new implementation uses a flat moonlit layout, per-sound artwork, hairline
grouping, and a persistent four-item bottom navigation.
