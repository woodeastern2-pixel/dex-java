# 잠온 UI 리디자인

원본 코드가 없는 상태에서 소유자의 검증용 APK를 기반으로 소스 구조를 복구한 새 기준선입니다.
복구 출처와 보존 범위는 `RECOVERY_PROVENANCE.md`에 기록했습니다.

APK v0.7.0에서 검증된 수면 루틴 기능 계약과 음원 리소스를 복구하고,
확정된 평면형·무테두리 UI 시안을 기준으로 다시 구성하는 Android 프로젝트입니다.

## 첫 품질 기준

홈 화면에서 상태 선택, 시간 설정, 사운드 조합, 루틴 시작까지 기존 동작을 유지하면서
카드형 라운드 박스와 외곽선 없이 확정 시안의 화면 위계를 재현합니다.

## 보존 범위

- 10가지 상태별 루틴 프리셋
- 1분~12시간 재생 시간
- 13개 수면 사운드와 개별 음량
- 무료 2개 / 검수용 Pro 4개 동시 조합
- 포그라운드 장시간 재생과 수면 기록
- 한국어 / 영어, 기록 삭제, 음원 라이선스

## 폐기 범위

- 반복되는 둥근 카드 컨테이너
- 청록색 외곽선과 테두리형 칩
- 모든 사운드에 같은 앱 아이콘을 사용하는 목록
- 화면별로 분리된 탐색 방식
